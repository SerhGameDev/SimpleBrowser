# SimpleBrowser

Учебный браузер на **WPF + C# + WebView2**.

Проект создан для профориентационного занятия со школьниками 9 класса.  
Главная цель — не изучить весь C# за одно занятие, а показать, как из XAML-разметки и нескольких простых методов получается настоящее Windows-приложение.

## Возможности

- открытие сайтов по адресу;
- переход назад и вперёд;
- обновление страницы;
- переход на домашнюю страницу;
- автоматическое обновление адресной строки при переходе по ссылкам;
- простой интерфейс, который легко изменить под себя.

## Технологии

- C#
- WPF
- .NET
- Microsoft WebView2

## Что изучают школьники

Во время работы с проектом можно познакомиться с:

- XAML-разметкой;
- `Grid`, `Button`, `TextBox`;
- свойствами элементов интерфейса;
- событиями `Click`;
- переменными;
- условием `if`;
- работой с объектами;
- взаимодействием XAML и C#;
- компонентом WebView2.

## Что можно изменить самостоятельно

Проект специально сделан простым, чтобы его было легко персонализировать.

Можно менять:

- название браузера;
- цвет кнопок;
- подписи на кнопках;
- размер окна;
- размер текста;
- домашнюю страницу;
- внешний вид интерфейса.
